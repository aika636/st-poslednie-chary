# Устройство расширения

Расширение ST без сборки: `manifest.json` (js `index.js`, css `style.css`, генерационный
перехватчик `cenaChudaInterceptor`).

## Слои
- `core/` — чистая логика без DOM и ST (время, rng и id приходят параметрами):
  - `rules.mjs` — шкала, пороги, цена каста; `state.mjs` — профиль и снимок состояния;
  - `journal.mjs` — события (`cast`, `rest`, `breather`, `effect_end`, `fracture_*`, `debt_settle`,
    `note_*`, `trait_*`, `faith_pray`, `nature_gift`, `scene_end`, `environment_set`, `profile_patch`…)
    и пересчёт состояния от снимка (`replay`); каст несёт копию карточки;
  - `chat-journal.mjs` — журнал в чате: события лежат в `extra.cenaChuda` сообщений, очередь команд
    до отправки и метаданные чата в `chatMetadata.cenaChuda` (режим, очередь, снимок), фиксация
    очереди в сообщение игрока, бросок d20, выбор сообщения для факта;
  - `prompt.mjs` — тексты для модели: блок состояния и факт хода, только проза, без чисел, id и бросков;
  - `catalog.mjs` — проверка и поиск карточек, свои заклинания; `data/` — каталог (см. `docs/catalog.md`).
- `view.mjs` — чистая часть слоя ST: чтение метаданных без записи, view для панели, тексты по типу
  генерации (для `quiet` и `impersonate` факта нет), настройки, шаблоны профиля.
- `index.js` — слой ST: настройки `extension_settings.cenaChuda` (`enabled`, `depth`, `templates`,
  `theme`), запись в чат через очередь промисов, подписки на события, кнопки.
- `ui.js`, `style.css`, `candle.js`, `glyphs.js`, `dice.js/.css`, `hint.js`, `fonts/`, `assets/` — оформление
  (`docs/ui.md`).

## Поток данных
1. Игрок ставит кастовые команды в очередь (панель или подсказка у поля ввода) — это `chatMetadata`.
2. `MESSAGE_SENT` → `commitPending`: очередь фиксируется в событиях сообщения игрока, d20 бросается
   один раз.
3. Перед генерацией `cenaChudaInterceptor` пересчитывает состояние (`computeChat`) и ставит два
   `setExtensionPrompt`: блок состояния (`IN_CHAT`, глубина из настроек, по умолчанию 1) и факт хода
   (глубина 0). Дополнительных запросов к модели, плашек под сообщениями и разбора ответов нет.
4. Состояние — всегда пересчёт журнала: правка или удаление сообщения, свайп не ломают его.
   Метаданные с чужой версией схемы панель не трогает и предупреждает один раз на чат.
5. При смене чата тексты промпта очищаются.

## Публичный API
`globalThis.CenaChudaAPI` (только чтение): `apiVersion`, `state()`, `statusBlock()`.

## Безопасность
Весь пользовательский и чат-текст в разметке проходит через `esc`; HTML из данных чата не вставляется.
Внешних запросов нет, шрифты локальные (`fonts/`, OFL).
