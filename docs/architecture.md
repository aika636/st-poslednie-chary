# Устройство расширения

Расширение ST без сборки: `manifest.json` (js `index.js`, генерационный перехватчик
`cenaChudaInterceptor`). Стили в манифесте не заявлены: `app.js` подключает `style.css`, стили кубика и шрифты через `<link>` с тем же `?v=`.

## Слои
- `core/` — чистая логика без DOM и ST (время, rng и id приходят параметрами):
  - `rules.mjs` — шкала (`scaleFor`), пороги, цена каста; ступень мастерства лежит в профиле (`profile.mastery`), шкалу считают из профиля, отдельно она не хранится; версия шкалы — поле `sv` (в профиле снимка и в `payload` действий: `sv: 2` — новая шкала; без него — прежняя, `legacySnapshot` в `state.mjs`, `computeChat` показывает текущую); `state.mjs` — профиль и снимок состояния;
  - `journal.mjs` — события (`cast`, `rest`, `breather`, `effect_end`, `fracture_*`, `debt_settle`,
    `restore`, `note_*`, `trait_*`, `faith_pray`, `nature_gift`, `scene_end`, `environment_set`, `profile_patch`…)
    и пересчёт состояния от снимка (`replay`); каст несёт копию карточки;
  - `chat-journal.mjs` — журнал в чате: события лежат в `extra.cenaChuda` сообщений, очередь команд
    до отправки и метаданные чата в `chatMetadata.cenaChuda` (режим, очередь, снимок), фиксация
    очереди в сообщение игрока, бросок d20, выбор сообщения для факта;
  - `prompt.mjs` — тексты для модели: блок состояния и факт хода, только проза, без чисел, id и бросков; служебные шапки и метки («[Persona's magic]», «Visibility:», «Fractures:») и поручение модели — по-английски, тексты карточек и проза состояния — по-русски; `statusBlock` и `turnFact` принимают `world` (приходит из `skin` настроек): имена чар в кавычках и источник берутся из мира, первое предложение описания мира заменяется его законами, переименованные слова поясняются одной фразой, у источника «договор» после черты добавляется строка о покровителе; проявление надлома, сказанное в факте хода, в списке надломов блока состояния не повторяется;
  - `worlds.mjs` + `data/worlds.mjs` — словарь сеттинга по коже (`worldOf(skin)`): названия чар, школ и источников, слова «напряжение/надлом/отдых», законы мира и покровитель; у `amethyst` и `tavern` словаря нет. Хранимые данные (карточки в событиях, профиль) не меняются — мир применяется только при показе и сборке текста для модели. Свои чары (`custom:*`) не переименовываются.;
  - `catalog.mjs` — проверка и поиск карточек, свои заклинания; `data/` — каталог (см. `docs/catalog.md`).
- `view.mjs` — чистая часть слоя ST: чтение метаданных без записи, view для панели, тексты по типу
  генерации (для `quiet` и `impersonate` факта нет), настройки, шаблоны профиля.
- `app.js` — слой ST: настройки `extension_settings.cenaChuda` (`enabled`, `depth`, `templates`,
  `theme`, `desire`, `free`, `searchWords`), запись в чат через очередь промисов (несколько чатов с несохранёнными правками не теряются, о несохранённом чужом чате пишется предупреждение), подписки на события (`event_types` или `eventTypes`), кнопки. `MESSAGE_SENT` возвращает промис фиксации: при вставке в прошлое таверна перечитывает чат с диска только после сохранения.
- `index.js` — загрузчик (см. ниже).
- `ui.js`, `style.css`, `candle.js`, `glyphs.js`, `dice.js/.css`, `hint.js`, `fonts/`, `assets/` — оформление
  (`docs/ui.md`). `ui.js` собирает содержимое страниц и чистые данные для оболочки (`tensionOf` — шкала, `tabsOf` — вкладки, `modeOf` — режим); внешний вид предмета (рамка, свеча, закладки, брелок режима, перетаскивание) отдаёт `shells/<предмет>.js` через реестр `shells/index.js`. В настройках `item` — предмет (сейчас только `tome`), `skin` — кожа предмета; `theme` продолжает писаться ради отката версии. Корень панели, кнопки и подсказки несут `data-item` и `data-skin`; `esc.js` — общие помощники разметки.

## Поток данных
1. Игрок ставит кастовые команды в очередь (панель или подсказка у поля ввода) — это `chatMetadata`.
2. `MESSAGE_SENT` → `commitPending`: очередь фиксируется в событиях сообщения игрока, d20 бросается
   один раз. Свайп и регенерация (`cenaChudaInterceptor`, тип `swipe`/`regenerate`): если очередь не пуста и
   `factTarget` указывает на сообщение игрока, очередь дописывается в него (`commitPending` с `append`: тот же бросок,
   автопроявление надломов, показ кубика, сохранение чата), затем пересчитываются промпты — факт хода уходит в этот же
   свайп. Пишется только в сообщение игрока: `extra` сообщений ИИ в таверне хранится по свайпам.
   Мгновенные виды (`INSTANT_KINDS`: передышка, отдых, «Восполнить», заметки, свойства, среда, правка профиля, проявление/снятие/принятие
   надлома, подробность чар) при действии из тома не встают в очередь: фиксируются тем же дописыванием в последнее
   несистемное сообщение игрока (`instantTarget`), чат сохраняется сразу. Если сообщений игрока ещё нет — обычная очередь.
   Последнее мгновенное действие помнит слой ST (в метаданные не пишется), оно отменяется `removeEvent` — событие
   удаляется из сообщения целиком; запоминание сбрасывается новым сообщением, свайпом, другим действием и сменой чата.
   События `LATE_KINDS` (отдых, передышка, «Восполнить»), дописанные в уже отправленное сообщение, получают `late: true`.
   `factRows` не отдаёт late-события самого целевого сообщения, зато отдаёт late-события ближайшего предыдущего
   сообщения игрока: следующий ход и все его свайпы/регенерации говорят их один раз, с префиксом «До этого хода …»
   (`rowLines` в `prompt.mjs`); через одно сообщение они уже не звучат. Условие `late` выставляет `commitPending`
   (`append`, сообщение уже `sent`); текст «чем» для `restore` чистит `cleanHow` (`journal.mjs`).
3. Перед генерацией `cenaChudaInterceptor` пересчитывает состояние (`computeChat`) и ставит два
   `setExtensionPrompt`: блок состояния (`IN_CHAT`, глубина из настроек, по умолчанию 1) и факт хода
   (глубина 0). В покое (напряжения, надломов, чар, долгов, свойств и недавних последствий нет) и без факта хода
   блок состояния короткий: имя, источник, внешний вид магии, покровитель, обеты и одна строка «магия не действует».
   Дополнительных запросов к модели, плашек под сообщениями и разбора ответов нет.
4. Состояние — всегда пересчёт журнала: правка или удаление сообщения, свайп не ломают его.
   Метаданные с чужой версией схемы панель не трогает и предупреждает один раз на чат.
5. При смене чата тексты промпта очищаются.
6. Выключенное расширение (`enabled: false`) ничего не вставляет в промпт и не фиксирует очередь при отправке; журнал и очередь в чате остаются как были.

## Свои заклинания
Лежат в настройках расширения (`customSpells`), общие для всех чатов; удалённые id — в `customDeleted`, чтобы перенос
не вернул их. Карточки старых чатов из `meta.customSpells` при открытии чата добавляются в общие по id (метаданные чата
не меняются; общая карточка главнее). Каст хранит копию карточки, поэтому правка и удаление прошлое и очередь не затрагивают.

## Поиск чар
`createCatalog(...).search(запрос, названия, свои слова)` (`core/catalog.mjs`): слово запроса — префикс слова названия/тега или имеет общую основу (префикс не короче `max(3, длина−2)`, от 4 букв); совпасть должны все слова. Теги — `core/data/search-tags.mjs` плюс свои слова игрока из настроек (`searchWords: { id: [слова] }`, общие для всех чатов, чистятся `cleanSearchWords`, пустое удаляет ключ; действие `setSearchWords`). Сначала находки по названию, затем по тегам; `why()` возвращает тег для подписи «по слову».

## Публичный API
`globalThis.CenaChudaAPI` (только чтение): `apiVersion`, `state()`, `statusBlock()`.

## Безопасность
Весь пользовательский и чат-текст в разметке проходит через `esc`; HTML из данных чата не вставляется.
Внешних запросов нет, шрифты локальные (`fonts/`, OFL).

Панель тома монтируется в shadow root (`#cc-panel-host`), стили подключены `<link>` внутрь; поиск элементов панели — через `shadowRoot`, а не `document`.

`index.js` — небольшой загрузчик: читает `version` из `manifest.json` (без кэша) и подгружает `app.js?v=<версия>`; все модули и стили подключены с тем же `?v=`, чтобы браузер не держал старые файлы после обновления.
Версия в адресах модулей совпадает с `version` в `manifest.json`. При смене версии `?v=` меняется и в относительных `url(...)` рантайм-CSS (`style.css`, `dice.css`, `shells/*.css`, `fonts/fonts.css`; кроме `data:`, `http(s):`, `#` и абсолютных путей), чтобы картинки и шрифты не держались в кэше под старой версией.
