# Последние чары

Расширение для [SillyTavern](https://github.com/SillyTavern/SillyTavern): магия персоны игрока, у которой
есть цена. Каждое чудо добавляет напряжение, а перегруз оставляет надломы — следы, которые не уходят
после отдыха. Расширение считает только цену; что колдовать и как это выглядит в сцене, решаете вы и модель.

## Установка
Extensions → Install extension → вставить ссылку на этот репозиторий → Install. Перезагрузить страницу.

## Как играть
- **Открыть том** — мини-свеча у поля ввода (на ней видно напряжение, например «2/4»).
- **Профиль — один клик.** В новом чате том спросит «Чья это магия?»: выберите источник, имя
  берётся из персоны.
- **Пять источников:** знание, кровь, вера, договор, природа. У каждого свой дар и свои надломы.
- **86 заклинаний в шести школах** плюс свои. Выберите чары → «В очередь» → отправьте пост:
  цена спишется один раз, модель получит описание чуда и его последствий.
- **Подсказка каста.** Напишите в посте название заклинания — над полем появится «✦ Название?»;
  нажатие ставит его в очередь.
- **Напряжение 0–4.** Колдовать можно и на полной шкале, но всё сверх неё становится надломом.
  «Передышка» снимает немного напряжения, «Отдых» — всё обычное. Надлом снимается своим условием,
  а тяжёлый можно принять навсегда.

## Режимы
- **Кубик** — исход решает бросок, его видно после отправки.
- **Сюжет** — чудо всегда удаётся, остаётся только цена.

## Темы
«Аметист» и «Как таверна» (цвета вашей темы SillyTavern). Есть компактный вид, телефонная вёрстка,
поддержка уменьшенной анимации.

## Данные
Состояние хранится в самом чате (метаданные и сообщения), внешних запросов нет.
