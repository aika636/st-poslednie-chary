# Последние чары

Расширение для [SillyTavern](https://github.com/SillyTavern/SillyTavern): магия персоны игрока, у которой
есть цена. Каждое чудо добавляет напряжение, а перегруз оставляет надломы — следы, которые не уходят
после отдыха. Расширение считает только цену; что колдовать и как это выглядит в сцене, решаете вы и модель.

## Установка
Extensions → Install extension → вставить ссылку на этот репозиторий → Install. Перезагрузить страницу.

## Как играть
- **Открыть том** — свеча-кнопка над полем ввода, её можно перетащить (в чате с профилем на ней видно напряжение, например «2/4»).
- **Профиль — один клик.** В новом чате том спросит «Чья это магия?»: выберите источник, имя
  берётся из персоны. В «Ещё → Профиль» можно выбрать ступень мастерства: Новичок, Умелый, Мастер.
- **120 заклинаний в семи школах** плюс свои. Выберите чары → «В очередь» → отправьте пост:
  цена спишется один раз, модель получит описание чуда и его последствий. Седьмая школа —
  «Чары влечения» для взрослых игр — выключена по умолчанию и включается в настройках.
- **Подсказка каста.** Напишите в посте название заклинания — над полем появится «✦ Название?»;
  нажатие ставит его в очередь.
- **Напряжение.** Шкала зависит от ступени: у Новичка 3, у Умелого 4, у Мастера 5, и растёт
  на 1 за каждый надлом, принятый навсегда (до 6). Колдовать можно и на полной шкале, но всё
  сверх неё становится надломом. «Передышка» снимает немного напряжения, «Отдых» — всё обычное.
  Надлом снимается своим условием, а тяжёлый можно принять навсегда.

## Источники и их дары
Дар срабатывает раз до отдыха. Знание, кровь и договор включаются кнопкой на листе заклинания
(она видна, только когда дар применим), вера и природа срабатывают сами.

| Источник | Дар |
|---|---|
| Знание | «Повторить по записи» — повтор последнего платного чуда стоит на 1 дешевле |
| Кровь | «Через кровь» — чудо ценой 2–3 вместо напряжения оставляет лёгкий надлом |
| Вера | «Милость» — первый перегруз до отдыха не оставляет надлома |
| Договор | «В долг» — чудо за 0 под условие покровителя; условие видно до каста |
| Природа | «Укоренение» — передышка снимает 2 вместо 1 |

## Свои чары
Вкладка «Свои» в каталоге и «Ещё → Свои заклинания»: создать, изменить, удалить. Встроенную
чару можно взять за основу кнопкой «Сделать своей» на её листе. Свои чары общие для всех чатов.

## Режимы
- **Кубик** — исход решает бросок, его видно после отправки.
- **Сюжет** — чудо всегда удаётся, остаётся только цена.
- **Режим бога** (в настройках) — касты без цены: напряжение не растёт, надломов нет. Уже
  накопленное остаётся.

## Оформление
Два предмета на выбор в «Ещё → Настройки → Предмет»:
- **Том** — книга со свечой; оформление «Аметист» или «Как таверна» (цвета вашей темы SillyTavern),
  есть компактный вид.
- **Телефон** — экран с кольцом напряжения; оформление «Городская мистика», «Киберпанк», «Космос».

Оба работают на узком экране и поддерживают уменьшенную анимацию.

## Данные
Состояние хранится в самом чате (метаданные и сообщения), свои чары — в настройках расширения.
Внешних запросов нет.
